# NPD-1 Evidence Model

Each executed port produces an existing R2/T8 governed observation with kind `network_port_discovery`.

The observation payload is bounded to:

- TCP port
- protocol
- explicit NPD state
- scope version
- task ID
- authorization reference
- observed duration

The observation identity is generated by the existing evidence canonicalization and SHA-256 identity logic. Project isolation and data-classification checks are applied before persistence.

The evidence lineage is therefore project → authorization/scope → trusted task → R15 NPD adapter → T5/R3 observation.
