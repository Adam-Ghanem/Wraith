# R11.6 Security Review

| Audit area | Result |
| --- | --- |
| Network/process capability | `internal/attacksurface` constructs local deterministic values only and has no HTTP, DNS, socket, resolver, shell, or subprocess behavior. |
| Evidence authority | Graph inputs are project-scoped references to R2/R5/R11.5 material. The graph does not mutate R2 observations or duplicate raw evidence values. |
| Project isolation | Node, edge, snapshot, campaign, task, storage, and CLI operations carry project ID. Cross-project source objects and snapshot lookups fail closed. |
| Graph integrity | Logical IDs and edge IDs are deterministic. Orphaned relationships, unknown node/edge types, duplicate identities, invalid risks, and unbounded campaign budgets are rejected. |
| Campaign safety | Generated tasks are non-executing recommendations with explicit limitations. R10.5, R1, and R3 remain the only lifecycle/authorization/transport authorities. |
| Data minimization | Local outputs contain only IDs, counts, classes, risk/gap summaries, and stated limitations; R11.6 does not persist credentials, tokens, request bodies, response bodies, payloads, or session data. |

The deferred work remains explicit: durable snapshot-membership history, richer JS/technology/auth relationships when normalized source evidence is persisted, approved R10.5 active-phase adapters, analyst campaign lifecycle mutation commands, report rendering, safe resume, and R12 reporting are not part of R11.6.
